## Four delivered variants

| Variant | Resolution | Function |
| --- | --- | --- |
| [`harmonia-with-text.png`](harmonia-with-text.png) | 1536 × 1536 | Text-bearing identity; sun center (768, 512), two-thirds of image height above bottom |
| [`harmonia-no-text.png`](harmonia-no-text.png) | 1200 × 1200 | Emblem without text; sun center (600, 600) |
| [`favicon.ico`](favicon.ico) | 16–256 px ICO | Multi-size icon derivative of no-text composition |
| [`harmonia-social-1200x630.png`](harmonia-social-1200x630.png) | 1200 × 630 | Wide social-media composition without text, from the no-text design family |

The **with-text** image places the radiating sun center at **(50%, 33⅓% from top)**, equivalently **two-thirds of image height above the bottom**. The **no-text** emblem places its radiating center at **(50%, 50%)**. These are composition-registration targets, not measurements or assertions about Planck-scale physics. The saved resolutions are the available raster resolutions, **not native 8K**; no claim of native 8K capture or generation is made.

The favicon is a multi-size ICO computed from the no-text image. The wide social-media variant shares the no-text emblem artwork design; it is a separate landscape rendering and not a pixel-exact enlargement of the square original. No text is added to either.

## Active use and historical distinction

The shared stylesheet [`styles/v1/jekyll-shell-harmonia.css`](../../styles/v1/jekyll-shell-harmonia.css) now points to the **with-text** file in this directory instead of the prior opaque-named image. The earlier source remains in the repository as an **inactive historical artifact**, not another active Harmonia artwork source.

The existing official programme-mark reference, ordinary identity logo, and global favicon assets have **not** been replaced by this scoped Harmonia operation. The [future brand-logo README](../brand-logo-readme.md) is intentionally a placeholder. Any broadened brand-wide designation is for the Architect to establish.
