# PortusSophia™ Library — Leanpub Books

**Rough draft v0.3 — for examination, not adoption.**

## Forum/theatre for fellowship

This working reference belongs to the developing **forum/theatre for fellowship**: a place in which existing representations, author-side working materials, publication references, and related public presentations may be encountered without requiring that they all have the same function, provenance, dissemination, or standing.

This README starts with links and distinctions **already supplied**, not with a presumed complete book collection. The phrase *forum/theatre for fellowship* is preserved as the Architect's wording; it is not a new governance category or a claim about access privileges.

## Leanpub as publisher and working space

The Architect identifies Leanpub as both **a publisher** and **a working space**. A book may be available to readers while author-side work continues, but that general possibility must not be turned into a claim about the current development state of every particular book.

```text
LEANPUB PUBLISHING SURFACE
    ≠
LEANPUB AUTHOR WORKSPACE

PUBLICLY AVAILABLE EDITION
    ≠
FINAL OR IMMUTABLE MANUSCRIPT

BOOK LISTING
    ≠
INDEPENDENTLY VERIFIED INVENTORY
```

## Sibling relation to SSRN

Leanpub books are received here as a **sibling collection to SSRN**, **not as the same collection and not at the same level of dissemination**. This difference is the Architect's present description of these materials, not a universal ranking of the Leanpub and SSRN platforms.

The existing [SSRN intake](../ssrn/README.md) separately records eleven supplied PDF originals with an Architect-designated **Distributed + Canonical** standing *within that library scope*, and a formal seal still pending. **None of those designations transfers automatically to Leanpub books.**

No Leanpub book is assigned a library category, canonical standing, or dissemination degree by this README alone. Specific books and editions will require their own reception and evidence.
